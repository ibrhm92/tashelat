# تسهيلات - تطبيق ويب للموبايل

تطبيق ويب بسيط ومتجاوب للموبايل مصمم لتسهيل إدارة الأعمال اليومية.

## المميزات

### 🏦 رصيد البنك
- تسجيل أرصدة البنوك بسهولة
- إرسال الأرصدة مباشرة إلى الواتساب
- حفظ البنوك المثبتة محلياً
- إضافة بنوك جديدة وحذفها
- دعم عملات متعددة (ريال، دولار، يورو، جنيه)
- إمكانية إدخال أرصدة بنوك متعددة في رسالة واحدة

## التقنيات المستخدمة
- HTML5
- CSS3 مع تصميم متجاوب
- JavaScript (Vanilla JS)
- LocalStorage للتخزين المحلي
- WhatsApp API للإرسال

## كيفية الاستخدام

### 1. رصيد البنك
1. اضغط على زر "رصيد البنك" من الصفحة الرئيسية
2. اختر البنك من القائمة أو أضف بنك جديد
3. أدخل الرصيد والعملة
4. يمكنك إضافة المزيد من البنوك بضغط "إضافة بنك آخر"
5. اضغط "إرسال للواتساب" لإرسال الأرصدة

## النشر على Cloudflare Pages

### الخطوات:
1. أنشئ حساب على [Cloudflare](https://cloudflare.com)
2. ادخل على Cloudflare Pages
3. اضغط "Create a project"
4. اختر "Upload assets"
5. ارفع جميع ملفات المشروع
6. سيتم نشر الموقع تلقائياً

### الملفات المطلوبة للنشر:
- `index.html` - الصفحة الرئيسية
- `bank-balance.html` - صفحة رصيد البنك
- `styles.css` - ملف التنسيقات
- `script.js` - ملف JavaScript العام
- `bank-balance.js` - ملف JavaScript لصفحة رصيد البنك

## التخصيص

### إضافة بنوك افتراضية
يمكنك تعديل قائمة البنوك الافتراضية في ملف `bank-balance.js` في دالة `loadBanks()`.

### إضافة عملات جديدة
يمكنك إضافة عملات جديدة في ملف `bank-balance.html` في قائمة العملات.

## التوافق
- متوافق مع جميع المتصفحات الحديثة
- مصمم خصيصاً للموبايل
- يعمل بدون اتصال بالإنترنت (ما عدا إرسال الواتساب)

- إمكانية التصدير والاستيراد
- إحصائيات وتقارير
